# teteocan_duelo_cosmico

Hola aqui anexo las actividades de creacion del juego.
Como primera actividad se realizaron los espacios donde se crearian los sprites.
Se creo el mazo, al darle click se despliegan las cartas, al hacer click en las cartas se selecciona una y se muestra en el centro.

Como actividad 2 solo se crearon los sprites en los objetos ya creados con anterioridad.
